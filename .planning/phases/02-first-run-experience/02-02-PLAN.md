    3. Implement `runInit()` following the exact wizard flow from D-01 through D-04:

       a. **Check existing config (D-02):**
          - Call `config.ConfigDir()` to get config dir path
          - Build `configFile := filepath.Join(configDir, "config.yaml")`
          - If file exists (`os.Stat` succeeds): prompt with `survey.Confirm` — message: `fmt.Sprintf("Config already exists at %s. Overwrite?", configFile)`, default: false
          - If user says no: print `"Config unchanged. Use 'tempus config set <key> <value>' for individual changes.\n"` to stdout, return nil
          - **Handle Ctrl+C:** check error from survey.AskOne — if `err == terminal.InterruptErr`, return nil (clean exit). Import `"github.com/AlecAivazis/survey/v2/terminal"`.

       b. **Step 1 — Timezone (D-01):**
          - `detectedTZ := config.DetectTimezone()`
          - `survey.AskOne(&survey.Input{Message: "Timezone:", Default: detectedTZ}, &timezone, survey.WithValidator(...))`
          - Validator calls `config.ValidateTimezone(ans.(string))`
          - Handle Ctrl+C same as above

       c. **Step 2 — Language (D-01):**
          - `detectedLang := config.DetectLanguage()`
          - `survey.AskOne(&survey.Select{Message: "Language:", Options: []string{"en", "es", "pt", "ga"}, Default: detectedLang}, &language)`
          - Handle Ctrl+C

       d. **Step 3 — Output directory (D-01):**
          - `survey.AskOne(&survey.Input{Message: "Output directory:", Default: "."}, &outputDir, survey.WithValidator(...))`
          - Validator calls `config.ValidateOutputDir(ans.(string))`
          - Handle Ctrl+C

       e. **Step 4 — Default alarm profile (D-01):**
          - `survey.AskOne(&survey.Select{Message: "Default alarm profile:", Options: []string{"adhd-default", "adhd-countdown", "medication", "single", "none"}, Default: "adhd-default"}, &alarmProfile)`
          - Handle Ctrl+C

       f. **Save config:**
          - Load or create config: `cfg, err := config.Load()`
          - Set all 4 fields via `cfg.Set("timezone", timezone)`, `cfg.Set("language", language)`, `cfg.Set("output_dir", outputDir)`, `cfg.Set("default_alarm_profile", alarmProfile)`
          - Each Set() call persists to disk via Save()

       g. **Show summary (D-03):**
          ```go
          fmt.Fprintf(stdout, "\n> Config saved to %s\n\n", configFile)
          fmt.Fprintf(stdout, "  Timezone:      %s\n", timezone)
          fmt.Fprintf(stdout, "  Language:      %s\n", language)
          fmt.Fprintf(stdout, "  Output dir:    %s\n", outputDir)
          fmt.Fprintf(stdout, "  Alarm profile: %s\n", alarmProfile)
          fmt.Fprintf(stdout, "\nNext: tempus create --start today --duration 1h\n")
          ```

    4. Add required imports: `"path/filepath"` (if not present), `"github.com/AlecAivazis/survey/v2/terminal"`.

    **Anti-patterns to avoid (per RESEARCH.md):**
    - Do NOT use `survey.Ask` with multiple questions — use `survey.AskOne` per step for sequential flow with early exit
    - Do NOT create a separate `internal/init/` package — keep in main.go per existing pattern until Phase 3 refactor
    - Do NOT add `--yes` flag — D-04 explicitly forbids it
