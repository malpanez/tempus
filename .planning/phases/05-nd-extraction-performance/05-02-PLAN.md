**Part A: Optimize DetectEventConflicts in internal/nd/nd.go**

Replace the current nested-loop O(n^2) implementation with sweep-line:

1. Filter out AllDay events into a `timed` slice.
2. Sort `timed` by StartTime using `sort.Slice`.
3. Linear scan: for each event i (from 1), walk backwards from j=i-1 while `timed[j].EndTime.After(timed[i].StartTime)`. For each overlap found, compute overlap duration and format conflict string.
4. Output format MUST match exactly: `"{ev1.Summary} ({HH:MM}-{HH:MM}) overlaps with {ev2.Summary} ({HH:MM}-{HH:MM}) by {duration}. Suggestion: move {ev2.Summary} to {HH:MM}"`
   - The "first" event in each pair is the one with earlier StartTime (timed[j]), the "second" is timed[i].
   - Suggestion time = timed[j].EndTime.Format("15:04") (same as current logic where suggestion = ev1.EndTime).
5. Use `FormatDuration` (now exported) for duration formatting.

**Part B: Add benchmark test in internal/nd/nd_test.go**

Add `BenchmarkDetectEventConflicts` that creates 1000 events (non-overlapping, 30min each, 5min gaps) and benchmarks `DetectEventConflicts`. This validates O(n log n) performance. Also add a variant with 1000 events where ~10% overlap to test realistic scenario.
