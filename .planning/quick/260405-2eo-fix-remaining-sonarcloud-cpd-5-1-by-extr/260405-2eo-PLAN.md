Create a private helper function in helpers.go:

```go
func valueAsSlice(v interface{}, itemFn func(string) string, splitFn func(string) []string) []string {
```

The function consolidates the shared type-switch pattern:
- `nil` case: return nil
- `[]interface{}` case: iterate, call `itemFn` on each `ValueAsString(item)`, skip empty, return slice
- `[]string` case: iterate, call `itemFn` on each item, skip empty, return slice
- `string` case: call `splitFn(x)` and return
- `default` case: format with Sprintf, if empty return nil, call `splitFn` and return

For the `[]interface{}` and `[]string` cases, `itemFn` transforms each individual element. For `ValueAsStringSlice`, `itemFn` is `strings.TrimSpace`. For `ValueAsAlarmSlice`, `itemFn` needs to expand each element through `calendar.SplitAlarmInput` -- but since that returns a slice, the approach needs adjustment.

REVISED approach -- use a callback that processes one string element and appends results to the output slice:

```go
func valueAsSlice(v interface{}, eachFn func(string, *[]string), splitFn func(string) []string) []string {
    if v == nil {
        return nil
    }
    switch x := v.(type) {
    case []interface{}:
        var out []string
        for _, item := range x {
            val := strings.TrimSpace(ValueAsString(item))
            if val != "" {
                eachFn(val, &out)
            }
        }
        return out
    case []string:
        var out []string
        for _, item := range x {
            if strings.TrimSpace(item) != "" {
                eachFn(item, &out)
            }
        }
        return out
    case string:
        return splitFn(x)
    default:
        val := strings.TrimSpace(fmt.Sprintf("%v", x))
        if val == "" {
            return nil
        }
        return splitFn(val)
    }
}
```

Then rewrite `ValueAsStringSlice` as:
```go
func ValueAsStringSlice(v interface{}) []string {
    return valueAsSlice(v,
        func(s string, out *[]string) { *out = append(*out, strings.TrimSpace(s)) },
        SplitDelimited,
    )
}
```

And `ValueAsAlarmSlice` as:
```go
func ValueAsAlarmSlice(v interface{}) []string {
    return valueAsSlice(v,
        func(s string, out *[]string) {
            for _, part := range calendar.SplitAlarmInput(s) {
                if strings.TrimSpace(part) != "" {
                    *out = append(*out, part)
                }
            }
        },
        calendar.SplitAlarmInput,
    )
}
```
